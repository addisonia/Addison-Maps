Fullstack Applications

Snowplow Tracker Dashboard

Video demonstration of the Snowplow Tracker Dashboard. This dashboard is a custom built Web GIS application designed to provide affordable, real-time, and historical GPS tracking for heavy machinery in extreme winter environments. It features a highly interactive interface where users can monitor live and past vehicle movements, visualize road clearance recency or vehicle speeds. The backend runs on a secure, multi-tiered architecture which includes a Linux VPS to handle raw hardware telemetry, Firebase for real-time data, BigQuery for economical long-term storage, custom Python APIs, a self-hosted Valhalla route-matching engine, and strict cybersecurity practices using Google Auth for user logins (and more!).

SnowSpotter Android App

Video demonstration of the SnowSpotter Android Application. This is an android app that shows all locations in North America that are currenty snowing. Users can sign in to load their saved UI preferences. App music is made by me.
